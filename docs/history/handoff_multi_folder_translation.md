# 複数フォルダ連続自動翻訳機能 仕様書（OS標準ピッカー・キュー追加方式）

## 概要
重く不安定だったカスタムダイアログを全廃し、Android OSネイティブの超軽量・高速なOS標準ピッカー（SAF: `OpenDocumentTree`）を活用して、異なる作品フォルダを自由に追加・連続翻訳できるシンプルな設計に刷新。

## 仕様とアーキテクチャ

### 1. OS標準ピッカーによるキュー追加方式
- **「選択」/「＋ 追加」ボタン:** OS標準ピッカー（SAF）がネイティブ速度で瞬時に起動。
- **選択中フォルダ一覧（キュー）:**
  - フォルダを選択するたびに、翻訳パネル内にチップス（`[× 作品A]` `[× 作品B]`）としてキューに追加。
  - 重複するフォルダは自動で排除。
  - 各チップの `×` ボタンで個別解除、`[ 全解除 ]` で一括クリア可能。
  - 複数選択時は「全 N フォルダ一括翻訳」と表示。

### 2. 複数フォルダ連続翻訳キュー (`ScrapingViewModel`)
- 選択されたフォルダ群を `selectedFolders` として保持。
- 翻訳開始時、フォルダ1（全話） ➔ フォルダ2（全話） ➔ フォルダN（全話）と自動でシームレスに連続実行。
- 連番ソート: 自然順（`compareNatural`）で `001.txt` → `002.txt` → `010.txt` 順に処理。
