## 実装内容
1. **プロンプト順序入力欄の常時表示**:
   - 「モデル設定」タブ上部に、現在適用中のプロンプト順序（例: `1, 1` や `3, 7`）を直接編集できるテキスト入力欄を配置。
2. **右側にアクションボタン（適用 ＆ プリセット⚙）を配置**:

   - 「プリセット⚙」ボタン: プリセット一覧ダイアログが開き、登録済みプリセットを選んで適用、または現在入力中の内容を新しいプリセットとして保存可能。
3. **データ同期**:
   - プリセット選択時に入力欄の内容も自動連動して更新。
