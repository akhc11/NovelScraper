# 引き継ぎ状況 - プロンプト設定のUX・堅牢化・直感性根本治療 (handoff_prompt_ux_and_robustness.md)

## 完了日: 2026-09-03

## 概要
敵対的レビューで洗い出した5つの課題（新規モデル継承、実効値リアルタイム可視化、全モデル強制一括同期、空欄安全フォールバック、翻訳ログの全モデル詳細表示）を根本治療した。

## 実装内容
1. `LlmSettingsDialog`:
   - 新規モデル追加時、現在の一括プロンプト順序を自動引き継ぎ
   - プリセットメニューに「⚡ 全モデルに強制一括適用 (個別保護を解除)」を追加
   - `ModelProfileCard` で保護OFF時に実効プロンプト順序をプレビュー表示
   - 空欄時のデフォルト `1, 1` フォールバックおよび保存時サニタイズ
2. `LlmTranslationEngine`:
   - 翻訳開始時ログに、全巡回モデルのプロンプト順序と「共通／個別」タグを一覧出力
3. 検証:
   - `LlmPipelineTest` 全件パス
   - `assembleDebug` 成功
