# 引き継ぎ状況 - 設定画面（SettingsPanel）の劇的軽量化・リコンポジション最適化

## 1. 概要・現象
- 設定画面で文字を入力する際、1文字ごとに全画面（MainScreen、WebView、Toolbar、全入力欄）が連鎖リコンポジションされ、深刻なタイピングラグ・スクロールカクつき・IME表示遅延が発生していた。
- 15個程度の固定フォームに対して LazyColumn の仮想化オーバーヘッドが余計にかかっていた。

## 2. 修正方針
1. **レイアウトの刷新 (LazyColumn → Column + verticalScroll)**:
   - 仮想化オーバーヘッドを排除し、1回のレイアウトパスでスムーズなスクロールを実現。
2. **ローカル状態管理とリコンポジションの局所化**:
   - パネル内での編集状態を localConfig で効率的に保持・管理。
   - 各入力欄（ConfigInputField）の再描画範囲を入力中のコンポーネントのみに局所化。
3. **機能・項目の完全維持 (ルール4厳守)**:
   - utoUrl を含む全13入力欄、プリセット操作、ダークモードトグル、説明書ダイアログを100%維持。
