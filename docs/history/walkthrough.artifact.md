# インスペクター＆プレビュー機能 強化 完了報告

## 実施内容
小説の抽出設定をより直感的かつ詳細に行えるよう、以下の機能を実装しました。

### 1. 常駐型マルチ・インスペクター・ツールバー
WebViewの上部に常駐する操作パネルを導入しました。
- **連続設定**: モード（タイトル、本文、次へ、除外）を切り替えて、画面遷移なしで複数の要素を一度に設定できます。
- **除外モード**: 広告やSNSボタンなどの不要な要素をタップして「除外リスト」に登録できます。タップした要素はその場で半透明になり、視覚的に確認できます。
- **保存機能**: すべての設定をまとめて一括保存し、プリセットに反映します。

### 2. 複数除外セレクタ（Exclude）機能
本文抽出前に特定の要素をDOMから削除する機能を実装しました。
- `ScraperConfig` に `exclude` フィールドを追加し、カンマ区切りで複数のCSSセレクタを指定可能です。
- 本文抽出ロジック (`ScrapingScriptBuilder`) が、これらの要素を自動的に削除してからクリーンな本文を生成します。

### 3. インタラクティブ・プレビュー
テスト実行結果の表示を Compose UI (`TestResultDialog`) に刷新しました。
- **タップで逆引き特定**: プレビュー内のテキストをタップすると、WebView側の該当要素が自動スクロールされ、強調表示（オレンジ枠）されます。
- **その場で除外**: テキスト横のゴミ箱アイコン（×）をタップすると、その要素が `exclude` リストに自動追加され、即座にプレビューが更新されます。

## 検証結果
- **構文チェック**: すべての変更ファイル (`MainActivity`, `ViewModel`, `ScriptBuilder`, `Dialog`) の静的解析をパスしました。
- **ロジック確認**: `ScraperConfig` の拡張、JS側からの JSON 通信、Compose でのダイアログ表示とコールバック連携が正しく構成されていることを確認しました。
