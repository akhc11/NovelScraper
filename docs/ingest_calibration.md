# Ingest v2 較正記録 (再現手順付き)

## 方法
Pythonで各言語サンプルを対象encodingで符号化→検証対象デコード (REPLACE) し、
FFFD率・文字種量・表被覆率を測定。陽性 (正規文) と陰性 (他言語の誤復号) の
分離点の中間に閾値を置く。測定scriptはリポ外 (Temp) にあるため、
再較正時は同手順で再測定すること。

## 単バイト族内識別 (バイト頻度表)
各言語サンプルの上位バイト分布から導出。全言語が自表で1位、
margin 1.33以上 (希薄なギリシャ語が最小)。margin rule 1.2 を採用。

## 共通 gate
- validity: FFFD率 5%超は失格 (poison 1-2Bは通過、破損文は脱落)
- UTF-8寛容予算: max(8個、0.1%) (実内容由来は1%を大きく超える)
- margin rule 1.2、短文の最小証拠量は min(50, max(10, len/4))
